API CVA — guía fácil

Qué es, para qué sirve y cómo usarla (sin tecnicismos).

En una frase
La API de CVA es un “catálogo en línea” de productos del mayorista CVA: te deja consultar precios, existencias, fotos y pedidos desde tu sistema (por ejemplo Exacto).

¿Para qué la usamos?

  • Buscar un producto y ver su precio
  • Ver si hay stock (en tu sucursal o en el almacén grande de Guadalajara)
  • Ver promociones
  • (Opcional) Hacer pedidos a CVA desde el sistema

Cómo funciona (5 pasos)

  1. Entrar — Con usuario y contraseña CVA pides un “pase” (token). Dura 12 horas. Sin ese pase no puedes consultar nada.
  2. Guardar el catálogo — Mejor bajar productos a tu base de datos de noche o varias veces al día. No pedir todo el catálogo cada vez que alguien abre una pantalla (puede pesar ~90 MB y se pone lento).
  3. Consultar 1 producto — Cuando cotizas, preguntas solo por esa clave: precio y stock al momento.
  4. Pedir (si tienen crédito) — Se puede crear un pedido a CVA; necesitan línea de crédito con ellos.
  5. Envío — Se puede cotizar flete (Paquetexpress) y, con permiso especial, registrar guías.
Regla de oro
Catálogo grande → sincronizar en segundo plano.
Precio/stock de un producto → consultar en el momento.

Dos formas de buscar un producto

Buscas por…Significado
clave (ej. PR-2586) Código interno de CVA. Es el más seguro.
codigo (número de parte) Código del fabricante (como en la caja del producto).

También puedes pedir que solo te muestren lo que sí tiene existencia (en sucursal, en CEDIS, o en ambos).

Pedidos — lo básico

  • Hace falta crédito con CVA.
  • Mandas: sucursal, productos (clave + cantidad) y si lleva flete o no.
  • Tipos de flete: SF = sin flete · FF = flete en la factura · FS = flete asegurado.
  • Hay modo prueba (test) para no generar pedidos reales.
¿Qué NO hacer?
No descargar el catálogo completo en cada cotización.
No depender solo de la API sin guardar datos en Exacto:
si CVA está lento o caído, tu sistema también se siente lento.

Datos útiles

  • Respuestas en JSON (formato de datos para programas)
  • Token válido 12 horas
  • Listados grandes vienen por páginas (aprox. 36 productos)
