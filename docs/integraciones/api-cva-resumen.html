Modelo de uso recomendado No uses el API como fuente on-demand masiva en runtime. Sincroniza catálogo a tu BD con jobs ETL; consulta en tiempo real solo producto individual (precio, stock, promo). Precios/existencias pueden cambiar sin aviso.

1. Flujo general

PasoQué hacer
1. LoginPOST /user/login → token Bearer (12 h)
2. AuxiliaresCatálogos: marcas, grupos, soluciones, ciudades, sucursales, paqueterías
3. Sync catálogoETL: lista_precios + precios_stock_ofertas (paginado)
4. Tiempo realMisma ruta con ?clave= o ?codigo= para 1 producto
5. Pedidoscrear_orden (requiere crédito) → listar / consultar / factura
6. EnvíosCotizar flete (Paquetexpress) · Guías (token aparte + Vo.Bo.)

2. Autenticación

POST /user/login
Body: {"user":"USUARIO","password":"CONTRASEÑA"} → id_cliente, clave_cliente, usuario, token. Header en rutas protegidas: Authorization: Bearer TU_API_TOKEN

3. Paginación

Listados: máx. 36 por página (lista_precios). Query ?page=N (default 1). Respuesta incluye paginacion.total_paginas y paginacion.pagina. Página inexistente → { message: "No se encontraron productos." }

precios_stock_ofertas usa batch: SM=50, MD=150, LG=500, XL=1500 (default SM).

4. Productos — endpoint principal

GET /catalogo_clientes/lista_precios — catálogo, filtros y enriquecer campos con flags booleanos en query.

Filtros de búsqueda

ParámetroUso
(sin params)Catálogo completo paginado — evitar si puedes
claveClave CVA (prioridad alta) → 1 producto
codigoNúm. de parte fabricante → 1 producto
marcaFiltra por marca (case-insensitive)
grupoFiltra por nombre de grupo
grupo2ID(s) de grupo, ej. 268 o 268,15462
descBúsqueda libre en descripción
SolucionID de solución (ver catálogo)
completos=1 + images=1Solo productos con imágenes HQ
exist0–4: filtro de disponibilidad (ver abajo)

Disponibilidad (exist)

existRegla
0Sin filtro (default)
1Solo stock en tu sucursal
2Solo stock en CEDIS (Guadalajara)
3Sucursal o CEDIS
4Disponible en todas las sucursales

Campos: disponible = tu sucursal · disponibleCD = CEDIS GDL · disponibilidad_sucursales = total nacional (con flag).

5. Precios, stock y ofertas (sync liviano)

GET /catalogo_clientes/precios_stock_ofertas · ETL recomendado
Catálogo paginado solo con precio, moneda, promoción e inventario por almacén. Ideal para refrescar varias veces al día.

Params: batch, MonedaPesos, TipoCompra, porcentaje, clave, codigo

Info técnica
GET .../informacion_tecnica?clave=
Imágenes HQ
GET .../imagenes_alta?clave= — más fresco que caché de lista_precios
